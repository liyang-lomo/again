## Usage

1. Clone this repository:

   ```bash
   git clone <your-repo-url>
   ```

2. Open and read the documents:

   - `README.md`: Chinese project overview
   - `README.en.md`: English project overview
   - `新建文本文档.md`: Markdown syntax practice content
